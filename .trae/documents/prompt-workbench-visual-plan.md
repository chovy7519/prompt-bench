# 「折光 PRISM」提示词工作台视觉方案

## Summary

设计一个面向个人创作者的中文提示词工作台，覆盖三条核心链路：

1. **收集**：保存网页来源、原始提示词、标签与个人笔记。
2. **学习**：将多条提示词加入学习集，查看 AI 提炼的结构、语气、约束和变量，再生成可编辑的新提示词。
3. **演示**：按需提供 Web、Three.js、图片作品预览；跳过演示不会影响提示词保存与导出。

本次仅交付页面结构、交互和视觉风格方案，不搭建工程、不编写业务代码、不接入真实 AI。

### 2. 产品概念与视觉方向

**名称：折光 PRISM**。将收集的提示词视作“入射光”，AI 学习过程视作“棱镜”，新提示词和作品是折射出的不同结果。

**风格：创作者暗房 × 精密仪器。** 使用深墨背景、暖白文字和荧光黄绿作为唯一主强调色；以细分隔线、样本编号和参数刻度建立专业感，避免常见的紫色渐变与通用卡片仪表盘。

| 设计令牌 | 取值 | 用途 |
|---|---|---|
| 墨黑 | `#101210` | 全局背景 |
| 深灰绿 | `#181C19` | 面板与侧栏 |
| 浮层 | `#222823` | 悬浮层、选中区域 |
| 暖白 | `#EEEDE4` | 主要文字 |
| 灰绿 | `#929B90` | 次要文字、说明 |
| 荧光芽绿 | `#D7F86B` | 主按钮、当前步骤、关键数据 |
| 雾青 | `#8BB9B1` | 来源链接、Three.js 类型标识 |
| 陶橙 | `#E99A6C` | 图片类型、警告提示 |

- 标题：中文使用思源宋体，营造编辑与策展感；英文使用 `Instrument Serif`。
- 正文：中文使用思源黑体；提示词正文使用 `IBM Plex Mono` 与中文等宽字体搭配。
- 背景叠加极轻颗粒和 24px 网格，仅在主画布出现，不影响正文阅读。
- 卡片以 1px 边框和错位编号区分层级，圆角控制在 6–10px，不使用大面积浮夸阴影。
- 核心识别元素是“三段式折射线”：采集、提炼、生成由一条折线串联，选中学习集时线条由灰变绿。

### 3. 全局应用框架

桌面端以 1440px 为设计基准：

- **左侧导航 224px**：品牌、提示词库、学习工作台、作品展、收藏集与标签；底部为本地空间状态和设置入口。
- **顶部栏 64px**：当前位置、全局搜索、快捷键提示、主按钮“采集提示词”。
- **主内容区**：随页面切换，不使用传统统计数字首页，登录后直接回到上次工作上下文。
- **右侧上下文抽屉 400px**：展示提示词详情、来源和版本，不挤压核心编辑区；可完全收起。
- 导航选中项使用左侧 2px 荧光线和细字重变化，不依赖大面积色块。

移动端不照搬三栏：底部保留“库 / 学习 / 作品”三个入口，学习步骤改为横向分段，详情使用全屏抽屉。

### 4. 页面一：提示词库

**目标**：让网上收集的提示词可检索、可比较、可快速加入学习集。

- 顶部为一句动态标题“样本库 / 已收集 128 条微光”，下方依次是搜索框、类型筛选、来源筛选、标签筛选和排序。
- 主区默认采用**双栏样本索引**：左侧 380px 为提示词列表，右侧为当前提示词完整内容与分析摘要。
- 列表项显示编号、标题、前两行摘要、来源域名、类型图标、标签和收藏状态；选中项仅改变边框与左侧标线。
- 详情区包含：原始提示词、可识别变量、个人笔记、来源链接、历史版本；底部固定“加入学习集”。
- 多选后底部浮出批量操作条，显示“已选 3 条 · 建立学习集”，避免用户逐条搬运。
- 卡片标签按用途分类：角色、结构、语气、约束、输出格式，而非堆砌随意颜色。

**采集弹窗**：

1. 默认提供“粘贴提示词”大文本框，其次提供“从链接整理”URL 输入框。
2. 右侧实时呈现整理预览：标题、正文、来源、类型、标签。
3. 保存前允许编辑，明确标注“AI 整理建议”，不让自动结果覆盖原文。
4. 链接尚未解析时展示线框扫描动效；失败时保留用户已输入内容。

### 5. 页面二：学习工作台

**目标**：把“AI 学习提示词”从黑盒按钮变成可理解、可干预的创作流程。

采用“样本—提炼—新提示词”三列布局：

- **左列 280px｜学习集**：已选提示词缩略卡、拖拽排序、移除和权重标识；顶部显示样本数量与覆盖类型。
- **中列 320px｜学习摘要**：以四组可折叠参数呈现“角色设定、叙事结构、语言风格、输出约束”；每组展示共性、差异和可采纳建议。用户可点击采纳或忽略。
- **右列自适应｜生成编辑器**：上方输入本次目标，下方为生成的新提示词；支持段落级编辑、版本切换、复制与保存。
- 三列顶部用折射线连接，当前步骤高亮；流程可往返，不设计为一次性向导。
- “生成新提示词”是唯一荧光绿主按钮，按钮旁提供创作倾向滑杆：**忠实样本 ↔ 大胆重组**。
- 生成后保留 V1 / V2 版本条，差异以细下划线和边注显示，不使用大面积红绿 diff。
- AI 学习摘要采用逐组出现的短动效，正文生成不使用夸张打字机效果，减少等待焦虑。

**空状态**：左侧先展示一张示例样本卡与“从样本库选择”入口；未选样本时中央不显示虚假分析，生成按钮禁用并说明原因。

### 6. 页面三：可选作品演示

演示是学习完成后的延伸步骤，以可收起的大画布呈现，而不是强制流程。新提示词保存后显示两个平级选择：“仅保存提示词”与“制作作品演示”。

顶部类型分段控件：

- **Web**：浏览器框预览，支持桌面 / 平板 / 手机宽度切换；侧栏展示页面结构、使用提示词和版本。
- **Three.js**：全幅 3D 视口，提供旋转、缩放、线框、背景和播放控制；右下方以轻量参数面板展示相机、材质与光照，不喧宾夺主。
- **图片**：主图加 4 张候选缩略图，支持对比查看；旁侧展示尺寸、风格、种子和关联提示词。

共同规则：

- 预览区始终保留“查看所用提示词”，建立样本到作品的可追溯关系。
- 生成中只在画布内显示进度和当前阶段，不阻塞返回提示词库。
- 失败状态提供重试与“仅保存提示词”，不丢失编辑内容。
- 没有演示时，作品展页面展示简洁空状态，不自动触发任何生成。
- 作品展采用策展式网格，Web 与 Three.js 使用宽画幅，图片保持原始比例；筛选后按类型重新排布。

### 7. 关键反馈与动效

- 页面进入：品牌折线先绘制，标题和面板以 40ms 间隔淡入，总时长不超过 360ms。
- 加入学习集：样本卡缩成一枚编号标签并沿折射线移动至导航计数，提供明确因果反馈。
- 面板hover：边框由灰转暖白，来源链接变为雾青；不使用卡片漂浮和大幅缩放。
- 所有动效支持 `prefers-reduced-motion`，关闭位移后仅保留透明度变化。
- 键盘焦点使用 2px 荧光绿外框；正文与背景对比度至少 4.5:1。
- 加载、空、失败、成功状态均提供文字，不仅靠颜色或动画表达。

## Assumptions & Decisions

- 这是个人创作者工具，不引入团队组织和复杂权限。
- “学习”在视觉层面解释为可编辑的特征提炼，不承诺真实模型训练能力。
- 演示生成完全可选，提示词可独立保存、复制与导出。
- 首版同时覆盖 Web、Three.js、图片，不支持视频和音频。
- 仅输出视觉与交互方案；不新增前端工程、组件代码或 AI/API 集成。
- 默认以桌面深度创作体验为主，同时定义移动端信息重排方式。

## Verification

方案评审时逐项确认：

1. 能从提示词库完成采集、查看、筛选、多选并加入学习集。
2. 能理解样本如何被提炼，并能干预摘要、生成和编辑新提示词。
3. 不生成作品也能完成保存与导出，流程没有强制阻断。
4. Web、Three.js、图片三种演示均有明确预览方式和关联提示词入口。
5. 桌面三栏与移动端重排规则一致，核心功能无遗漏。
6. 空、加载、失败、成功及键盘焦点状态均有定义。
7. 全方案仅包含视觉设计决策，不隐含真实 AI 或工程实现已经交付。
